# Assets

Candymates draws everything itself (candies, effects and the board are drawn on a canvas) and synthesizes its sound effects with Web Audio.

| Path | Used for |
|------|----------|
| `audio/mochamusic-sugar-rush.mp3` | Background music during play (quiet, crossfaded loop) |
| `image/candymates-logo.png` | Optional lobby title logo. Until it exists, a colourful text title is shown. |

The UI font is [Geist Pixel](https://fonts.google.com/specimen/Geist+Pixel), loaded from Google Fonts.
